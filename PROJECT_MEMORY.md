## 1. Project Overview

### Challenge Statement

**Kannada for Everyone** — Help people learn practical Kannada through everyday conversations, vocabulary, and guided practice.

### Project Vision

Kannada Quest is an interactive, mission-based application designed to help non-Kannada speakers develop enough conversational Kannada to manage everyday situations.

The primary goal is **practical communication rather than formal Kannada script learning**.

## 2. Confirmed Product Requirements

### 2.1 Language Format

- All Kannada used in the learning experience must be written in **Romanized Kannada (English letters)**.
- Kannada script must not be used in the learning experience.
- The application will have three difficulty levels: Beginner, Intermediate, and Advanced.

### 2.2 Beginner Mode

- Mission-based questions.
- Multiple-choice responses.
- English translations displayed alongside response options.

### 2.3 Intermediate Mode

- Mission-based multiple-choice questions.
- No English translations alongside response options.
- Uses familiar and basic Kannada vocabulary so learners can infer meaning.

### 2.4 Advanced Mode

- Free-form, AI-powered conversational role-play.
- Learners type responses in Romanized Kannada.
- No multiple-choice responses.
- The AI must accommodate reasonable spelling variations.
- Feedback and interaction should prioritize successful communication rather than rigid spelling correctness.
